    Zoto Sans Vai¶

    Zoto Sans Vai is a design for the Vai script.

    It contains 304 glyphs, and supports 305 characters from the Unicode blocks: Vai.

    Supported writing systems¶

    Vai¶

    Vai (ꕙꔤ) is an African syllabary, written left-to-right. Used in Liberia and Sierra Leone for the Vai language (115,000 speakers). Created in the 1830s by Mɔmɔlu Duwalu Bukɛlɛ. Has 212 symbols. Possibly influenced by the Cherokee syllabary. Read more on ScriptSource, Wikipedia, Unicode, Wiktionary.
